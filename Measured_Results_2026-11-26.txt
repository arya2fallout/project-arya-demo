Interpretation
Decode rate uses the runtime token count and evaluation duration. TTFT measures receipt of the first nonempty
streamed chunk, including loading and prompt processing. p95 is nearest rank. Different response lengths and model
defaults prevent a simple causal speed ranking. A successful API call does not establish a complete or correct
answer.

2. Bridge results
The initial benchmark returned 30/30 successful matched status results: median 22.75 seconds, p95 23.05 seconds.
The live safety phase found expiration and filename-replay enforcement missing. Only newly created dummy files
were used.
The repair added durable claims before dispatch, deadline checks and replay protection across worker restarts. Its
first regression batch returned 30/30 transport matches but 0/30 healthy OpenCode checks because an inherited
PowerShell module path broke credential-helper command discovery. That failure was retained, diagnosed and
corrected without changing the stored credential.

Scope of the safeguards
Identity checks cover command filenames and optional request IDs at the Drive-worker boundary. Expiry is enforced
when supplied; legacy requests without it remain compatible. A crash can leave an uncertain claimed operation
blocked for manual inspection. The ledger must be retained. These tests do not certify every direct tool, all crash
modes or whole-machine security.
3. Resource sampling
297 samples were collected at a one-second target interval plus sampling overhead. RTX 3060 Ti observed maxima:
4,570 MiB used VRAM, 66.56 C and 199.93 W reported board power. Whole-system used RAM peaked at 12.02 GB
(decimal). GPU memory includes other clients; sampled peaks can miss brief spikes. Board power is not wall energy.
No electricity-cost or savings claim is made.

Response review
Three context-on answers correctly identified port 8080 but failed the contiguous phrase matcher. Assistant review
therefore found the core facts semantically correct in all 30 answerable responses, while also flagging one added
creation-time assumption not explicit in the evidence. Without context, one response invented a source ID.
Independent human adjudication remains outstanding. The deterministic keyword baseline passed 35/35; it is not a
language model.
Proposed next work
Freeze an independently authored held-out set before tuning. Investigate the long prompt-processing outlier with
repeat runs and controlled cache conditions. Benchmark the existing 16 GB GPU under matched settings before
requesting higher-memory hardware. Add mobile measurements only after recording an actual device, application
version, model and controls.
Evidence and disclosure
Full raw records, prompt set, model digests, settings, hashes, failed outcomes and repair tests are retained privately
under PA-LIVE-20261126 and PA-REPAIR-20261126. This summary removes personal filesystem paths, process
IDs, private account identifiers, credentials and raw operational logs. No model weights or private conversations are

certification, sustained stability claim, cross-device speedup or sponsor award is asserted.
